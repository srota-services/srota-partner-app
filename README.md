# Srota Partner App

Web client for Srota partner organizations and authors.

## Requirements

- **Node.js** `26.4.0` (see `.nvmrc`)
- **npm** `11.17.0`

Switch Node with your version manager from this directory:

```bash
nvm use
# or: fnm use
```

Install the required npm version globally if needed:

```bash
npm i -g npm@11.17.0
```

All npm scripts enforce these versions before running. Use `npm run check:runtime` to verify your environment.

## Development

```bash
npm install
npm run dev
```
